# Content Templates — Section Outlines per Archetype

Each archetype lives in `_archetypes/<name>/index.html` and is copied into a slug directory by the `/new-page` skill. This doc captures *what each section should contain* — a writing brief, not a code spec.

## Homepage (`index.html`)

| Zone | Section | Content brief |
|---|---|---|
| Z1 | Header | Logo + 4–5 nav links |
| Z2 | Hero | Headline (8–14 words), subhead (15–25 words), 2 CTAs (primary + outline) |
| Z3 | Services | 3–6 service cards with name + 1-sentence summary |
| Z4 | Client logos | 8–16 client wordmarks |
| Z5 | Reviews | 2–4 testimonials with name, role/company, optional rating |
| Z7 | Featured work | 3–6 case study cards |
| Z8 | CTA | Closer headline + single CTA |
| Z9 | Footer | 3-column: brand blurb, sitemap, contact |

## Service page (`_archetypes/service/`)

| Section | Content brief |
|---|---|
| Hero | Service name + 1-sentence "what it is" |
| Entity declaration | 1-paragraph definition of the service (this is the SEO/LLM "aboutness" anchor) |
| Long-form description | 2–4 paragraphs: who it's for, how you deliver it, what's unique |
| Feature list | 3–5 features with icon + title + 1-sentence description |
| Pricing block | Hourly / half-day / full-day / project (whichever fits) |
| Related work | 3–4 case studies that used this service |
| CTA | "Ready to start?" + contact button |

## Case study (`_archetypes/case-study/`)

| Section | Content brief |
|---|---|
| Hero | Client name (eyebrow) + project title + 1-sentence summary, full-bleed background image |
| Lead paragraph | 50–100 word opener — the "why this project mattered" |
| Challenge | 1 paragraph: what the client needed and why it was hard |
| Approach | 1–2 paragraphs: your process, tools, and creative POV |
| Results | 1 paragraph: the outcome with specifics |
| Metrics grid | 3–4 numeric callouts (impressions, runtime, deliverables, etc.) |
| Tech specs | 3 columns: tools, deliverables, team |
| Testimonial | 1–2 sentence quote + name + role |
| Gallery | 3–9 supporting images |
| Z7 related | 3–4 sibling case studies |
| CTA | "Have a similar project?" |

## Content page (`_archetypes/content/`)

For about, FAQ, glossary, news articles, anything that doesn't fit service or case study.

| Section | Content brief |
|---|---|
| Hero | Page title + 1-sentence description |
| Lead paragraph | Set the topic |
| Body | Free-form prose with h2/h3 sub-headings |
| Z7 related | 3–4 sibling content pages |
| CTA | Light closer |

## Voice rules per archetype

- **Service pages**: confident, factual, "we" voice
- **Case studies**: storytelling, past tense, "the client" or named
- **Content pages**: conversational, "you" voice for instructional content
- **Homepage**: high-energy, short sentences, present tense

## Word counts (suggested, not enforced)

| Page type | Total words |
|---|---|
| Homepage | 300–500 |
| Service page | 600–1000 |
| Case study | 500–900 |
| Content page | 400–1500 (varies) |
| FAQ | 50–100 per Q&A |
